# SRISTI 2K26

Official web application for the SRISTI 2K26 technical fest of Jalpaiguri Government Engineering College.

## Project Structure

- `frontend/` — React + TypeScript + Vite frontend
- `supabase/` — Supabase backend, database migrations, Edge Functions and seed data
- `docs/` — Project and API documentation
- `scripts/` — Development and maintenance scripts

## Development

### Frontend

```bash
cd frontend
npm install
npm run dev
